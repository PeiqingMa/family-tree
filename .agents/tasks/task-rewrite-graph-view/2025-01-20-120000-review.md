# D3-based family tree graph rewrite (v1)

The graph view was rewritten from scratch: `@xyflow/react` + dagre removed, replaced with a custom D3.js SVG renderer and a purpose-built generational layout algorithm. The new component renders circular avatar nodes in top-down generational rows, connects couples with marriage lines (dashed for divorce), and draws stepped parent-child paths. Interactions include click-to-center-and-highlight (ancestors, descendants, spouses) and double-click for a person detail popup. The AncestryView route became a thin wrapper that delegates to GraphView with a URL-driven preselection.

**Verdict**: NEEDS_CHANGES

## Issues

1. **Render loop on selection** - `selectedId` in the main useEffect dependency array causes full SVG teardown/rebuild on every click. Remove it from deps; apply highlight/animation in a separate effect or via D3 selections on existing DOM without triggering a re-render.

2. **Cycle non-termination in generation assignment** - The fixpoint loop in `graphLayout.ts` that unifies spouses and propagates children has no iteration cap. Add an iteration cap (e.g., `while (changed && iterations++ < nodeIds.length * 2)`) to prevent infinite loops on malformed data.

3. **No loading state on popup fetch** - `handleNodeDblClick` calls `getPerson(id)` with no loading indicator. Show the popup immediately with a loading spinner/skeleton while the fetch is in progress.

4. **Click/dblclick ambiguity** - Both click and dblclick are registered on the same element with no delay/debounce. Every double-click fires two click events first, causing the selection highlight to flash and the view to pan before the popup opens. Use a short timer on click (250ms) that cancels if a dblclick arrives.

5. **Background click deselects during pan** - The `svg.on('click')` handler deselects on any background click, including at the end of a pan gesture. Track whether the last interaction was a drag (e.g., compare mouse positions or use a flag set in the zoom handler) and skip deselect if so.

6. **No keyboard accessibility** - Graph nodes are SVG `<g>` elements with no `tabindex`, `role`, or keyboard event handlers. The popup has no focus trap. Add basic keyboard support (tabindex on nodes, Enter/Space to select, Escape to close popup).
